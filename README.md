## `~/sobre`

Sou Daniel, desenvolvedor em formação com foco principal em **Python e back-end**. Gosto de entender como as coisas funcionam por dentro: regras de negócio, persistência de dados, autenticação, terminais e pequenos sistemas que resolvem problemas reais.

Este perfil acompanha minha evolução por meio de projetos simples, melhorias constantes e experimentos que podem ser executados localmente. A prioridade é construir uma base sólida antes de aumentar a complexidade.

## `~/projetos`

### [`lanchonete-express`](https://github.com/NoveuzZ/lanchonete-express)
Sistema de vendas em terminal com autenticação, categorias, carrinho, formas de pagamento e histórico local de pedidos.

### [`sistema-de-login-txt`](https://github.com/NoveuzZ/sistema-de-login-txt)
Exercício de Python para cadastro, autenticação e persistência local. Um registro da base de lógica e manipulação de arquivos.

### [`historico-de-pedidos`](https://github.com/NoveuzZ/historico-de-pedidos)
Consulta e filtragem de pedidos vinculados ao usuário autenticado, mantendo a continuidade dos estudos de persistência e busca.

### [`noxdesk`](https://github.com/NoveuzZ/noxdesk)
Painel local de tarefas e estudos em Python, com interface responsiva e API local para computador e celular.
